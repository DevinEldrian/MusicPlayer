    ☁ Melo Private Vault

    Musik hanya dapat dibuka oleh akunmu. Login di HP atau PC lain untuk memuat koleksi yang sama.

     Lirik lagu

    Gunakan format LRC [mm:ss.xx] untuk lirik yang bergerak sesuai lagu, atau gunakan teks biasa.

     Tambah Lagu dari URL

    Masukkan tautan langsung file audio (MP3/FLAC/WAV) yang dapat diakses browser. Tautan disimpan di perangkat ini. Untuk berbagi koleksi antarperangkat, gunakan manifest pustaka online.

     Musik online lintas perangkat

    Lagu yang disimpan di browser menggunakan IndexedDB, sehingga tidak otomatis berpindah ke perangkat lain.

    1. Klik Paket Online ↓ untuk membuat ZIP berisi lagu-lagu lokal dan library.json.
    2. Ekstrak ZIP, lalu upload isi folder music/ ke folder docs/music/ di repository GitHub.
    3. Refresh situs GitHub Pages. Semua perangkat dapat memutar lagu dari manifest tersebut.

    Penting: GitHub Pages bersifat publik. Hanya unggah musik yang kamu punya hak untuk membagikannya.
